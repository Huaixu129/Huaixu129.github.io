腾讯一面/二面定制化面试清单 (基于简历深度挖掘)

1. 计算机网络与操作系统 (腾讯必考底层)

  • 简历提到掌握TCP/IP协议栈（三次握手/拥塞控制）及HTTP/HTTPS原理 。讲一下TCP拥塞控制的完整流程？如果此时发生粘包，怎么解决？

  • 写了熟悉Linux常用命令。如果线上发生缺页中断，或者用top查看到CPU飙高，你的完整排查链路是什么？结合你处理CPU飙高故障的理论基础详细说明 。

  • TCP四次挥手中 TIME_WAIT 状态的作用是什么？在高并发抢课或抽奖场景下，出现大量 TIME_WAIT 怎么处理？

2. Java核心与JVM调优

  • 简历写了熟练掌握HashMap和PriorityQueue等集合体系。PriorityQueue底层怎么维护树结构的？HashMap拉链什么时候转红黑树，为什么不直接设置单一阈值8？

  • 掌握JVM内存模型与GC算法（CMS/G1）。G1回收的具体过程是什么？如果线上系统（如灵犀活动引擎）在秒杀时G1停顿过久，你怎么调优？

  • 简历提到具备处理OOM的理论基础 。详细讲讲在哪些情况下会出现OOM？怎么排查和解决？

3. 高并发编程 (JUC)

  • 简历提到透彻理解JMM内存模型、AQS锁机制及CAS无锁编程 。AQS底层是怎么实现锁的？
  • 简历写了对比研究过ConcurrentHashMap演进差异 。详细讲讲1.7到1.8的结构和锁机制差异？
  • 具备复杂场景下的线程池定制与调优经验。你在UniSchedule项目中优化线程池模型时，核心线程数和最大线程数等参数是怎么确定的？

4. 数据库 MySQL

  • 简历提到深入理解InnoDB索引优化及MVCC机制。MySQL的Undo log、Redo log和Binlog分别有什么作用？
  • 结合MVCC机制讲讲，它是怎么解决幻读问题的？
  • 简历写了构建MySQL全量/冷数据存储。在海量数据下，你的索引是怎么优化的？如果发现B+树层级过高，怎么处理？

5. 缓存架构 Redis

  • 熟练掌握Redis核心数据结构（ZSet/SkipList）。跳表是怎么实现的？
  • 针对ZSet单点瓶颈，你设计了“纵向分桶+多线程扫描”策略 。具体怎么分桶？Hash路由的策略是什么？多线程扫描时怎么保证线程安全？
  • 针对黑名单过滤、奖品库存校验，运用Redis多种数据结构（Set、Hash）进行内存级运算。这里为什么选Set和Hash？底层的编码结构是什么？
  • 简历提到理解持久化与淘汰策略。在高并发场景下，Redis主节点挂了怎么办？怎么保证高可用？

6. 分布式中间件 Kafka 与 Spring Cloud

  • 深入理解Kafka高吞吐架构（零拷贝/分区机制） 。讲讲零拷贝底层用到了哪些系统调用？
  • Kafka 能实现极高吞吐量，核心在于分区（Partition）并发、顺序写磁盘以及零拷贝技术。

    • sendfile()： 这是解决网络传输最核心的系统调用。传统 IO 需要经历“磁盘 -> 内核层 -> 用户层 -> 内核层 Socket -> 网卡”四次拷贝和四次上下文切换。Kafka 在消费者拉取数据时，直接调用操作系统的 sendfile()（在 Java 中是 FileChannel.transferTo()）。数据直接在内核空间中从页缓存（Page Cache）通过 DMA 引擎拷贝到网卡，全程不需要 CPU 参与，也不经过用户态，将拷贝次数减到了最少。

    • mmap()（内存映射）： Kafka 在读写稀疏索引文件时使用了 mmap（Java 中的 MappedByteBuffer）。它将磁盘文件直接映射到用户态的内存地址中，用户进程像读写内存一样读写文件，节省了用户态到内核态的拷贝开销。

  • 具备解决消息积压、重复消费等生产环境问题的实战经验。针对百万级弹性抽奖系统，你是怎么保证消息队列可靠、幂等的？怎么做到不重不漏？
  • 深入理解Spring IoC/AOP原理及Bean生命周期。你在微服务架构重构中，AOP具体应用在哪些业务解耦场景里了？
  • 熟悉Docker核心原理。容器化部署时，网络和存储隔离是怎么实现的？

7. 场景设计与项目架构：UniSchedule

  • 简历提到基于Spring Cloud Alibaba实现调度核心与校园业务模块彻底解耦。Nacos的服务注册和发现机制底层是怎么工作的？
  • 研发了Migrator异步预取模块。异步数据搬运时，MySQL到Redis怎么保证不丢不乱序？你的动态时间窗口算法是怎么设计的？
  • 利用JProfiler定位锁竞争热点，引入Redis批处理将QPS从500提升至4800+详细推演一下这段优化过程，单机性能瓶颈具体卡在CPU还是网络IO？
  • 引入“状态机+CAS乐观锁”幂等校验机制。CAS自旋失败了怎么处理？ABA问题在这里会有影响吗？

8. 场景设计与项目架构：灵犀活动引擎

  • 简历写了系统性能峰值突破至7000 QPS。请求到网关层后，你的限流策略是怎么做的？
  • 利用Redis承载中间态数据与热点缓存，配合MySQL持久化落地。缓存和数据库怎么保证最终一致性？如果高并发下出现缓存击穿怎么防范？
  • 创新性地设计了奖品中奖概率区间算法。高性能随机数生成器在高并发下会有性能损耗吗？怎么保证绝对公平？
  • 基于Redis实现分布式锁机制防超发。锁过期了但业务没执行完怎么处理？有没有考虑过Redisson的看门狗机制？
