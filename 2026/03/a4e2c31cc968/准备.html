6. 分布式中间件 Kafka 与 Spring Cloud

  • 深入理解Kafka高吞吐架构（零拷贝/分区机制） 。讲讲零拷贝底层用到了哪些系统调用？
  • Kafka 能实现极高吞吐量，核心在于分区（Partition）并发、顺序写磁盘以及零拷贝技术。

    • sendfile()： 这是解决网络传输最核心的系统调用。传统 IO 需要经历“磁盘 -> 内核层 -> 用户层 -> 内核层 Socket -> 网卡”四次拷贝和四次上下文切换。Kafka 在消费者拉取数据时，直接调用操作系统的 sendfile()（在 Java 中是 FileChannel.transferTo()）。数据直接在内核空间中从页缓存（Page Cache）通过 DMA 引擎拷贝到网卡，全程不需要 CPU 参与，也不经过用户态，将拷贝次数减到了最少。

    • mmap()（内存映射）： Kafka 在读写稀疏索引文件时使用了 mmap（Java 中的 MappedByteBuffer）。它将磁盘文件直接映射到用户态的内存地址中，用户进程像读写内存一样读写文件，节省了用户态到内核态的拷贝开销。

  • 具备解决消息积压、重复消费等生产环境问题的实战经验。针对百万级弹性抽奖系统，你是怎么保证消息队列可靠、幂等的？怎么做到不重不漏？
